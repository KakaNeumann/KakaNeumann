## Projeto em destaque

### 💊 LembreMed

Aplicativo Android desenvolvido com Flutter e Dart para auxiliar pessoas idosas na organização e no acompanhamento dos horários de seus medicamentos.

Principais recursos:

- notificações locais com som e vibração;
- cadastro de medicamentos, doses e horários;
- histórico das doses confirmadas;
- foto de referência e preenchimento por voz;
- persistência local dos dados;
- interface acessível e navegação simplificada.
